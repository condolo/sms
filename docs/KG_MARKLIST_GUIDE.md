# Msingi — Kindergarten Marklist Guide

**Audience:** Kindergarten class/subject teachers entering competency-band scores in the Markbook.

## 1. How Kindergarten scoring is different

Every other section of the school enters a number out of 100 per subject. Kindergarten doesn't — instead, each subject has a short list of **indicators** ("Able to recite the alphabet A–Z", "Reading well") and the teacher rates each student against each indicator using a **band** your school has defined (for example Excellent / Good / Developing / Needs Support), or in some templates a 1–5 scale presented the same way. The report card then shows the student's band for each indicator and subject — not a percentage.

There are two separate steps, done in two separate places on the same screen, and mixing them up is the single most common point of confusion:

1. **Set up the indicator list for this term** — what you're assessing (just the wording, no scores yet).
2. **Score each student** — open one child at a time and pick their band for every indicator.

Adding an indicator in Step 1 does **not** ask you to score anyone — the band dropdown only appears once you open a specific student in Step 2.

## 2. Open the Markbook

1. Go to **Exams → Markbook**.
2. At the top, choose **Year → Term → Class → Stream (if your class has streams) → Subject**.
3. If this class/subject uses competency bands, the screen changes automatically to the Kindergarten entry view — you'll see the subject name and "Competency-band entry" at the top instead of the usual numeric grid. There is nothing extra to turn on.

## 3. Step 1 — Set up this term's indicators

This is the **"Indicators for this term"** panel near the top of the screen.

1. Expand **Indicators for this term** if it isn't already open.
2. Choose **Add indicator** and type what you're assessing this term (e.g. "Reading well"). Save.
3. Repeat for every skill/competency you want to report on for this subject this term.
4. To fix wording later, edit the indicator in this same panel. To remove one no longer needed, delete it here.

This list is **per class, per subject, per term** — it's normal for it to be empty at the start of a new term even if last term had entries, and normal for it to differ subject to subject. Nothing here is visible to a student or scored yet; it's just naming what you're about to assess.

## 4. Step 2 — Score each student

Below the indicator list is the student table, one row per child in the class/stream, with a running count ("2/3 indicators scored").

1. Find the student and choose **Score** (or **Edit scores** if some marks are already saved).
2. A panel opens listing every indicator you set up in Step 3, one row each.
3. For each indicator, open its dropdown and pick the band that matches the child's performance (or the 1–5 scale value, if that's how your school's template is set up). There is no number to type — picking the band is the whole entry.
4. Once every indicator has a band, save. The student's row updates to show all indicators scored.
5. Repeat for the rest of the class.

You can go back and change a saved band at any time before the report card is locked — open the student again, change the dropdown, save.

## 5. If the screen won't let you score

- **"Locked"** badge at the top, or a banner saying the report card has been published: entry is closed because report cards for this term have already gone out. Ask an administrator to unlock it for a correction — don't wait for it to open on its own.
- A student is missing from the list entirely: check they're enrolled in this subject for this class/stream and marked active — the Markbook only lists currently enrolled, active students.

## 6. Previewing and printing before publish

Before an administrator publishes report cards, there is **no "Download PDF" button** — that only appears on a report card once it's published, because the content is still provisional until then. To see or hand out something on paper before publish:

1. Go to **Report Cards**, find the student (or the whole class), and open the **preview**.
2. Use **Print** (or the class-wide **Print** button to print/save every card in the class as one document).
3. In the print dialog, choose **Save as PDF** instead of a physical printer if you need a file rather than a paper copy.

This preview reads live from whatever is currently saved in the Markbook, so re-check it after making any last-minute score changes — it isn't a snapshot.

## 7. Common mistakes to avoid

- **Typing the indicator name expecting to also score it right there** — adding text under "Indicators for this term" only defines what you're assessing. You still have to open each student under Step 2 to actually pick their band.
- **Leaving an indicator's wording vague after scores are already saved against it** — rename it precisely before scoring starts where possible; a wording change after scoring doesn't change anyone's saved band, it only changes the label shown on the report.
- **Expecting a PDF download before publish** — see Section 6; use Print → Save as PDF instead, and wait for publish for the direct download link.
