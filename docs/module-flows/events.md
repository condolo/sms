# Events & Calendar

## Add an event

1. Open **Events** and choose **New Event**.
2. Enter the title, date/time, event type, description, and audience/class where available.
3. Review whether it is school-wide, class-specific, staff-only, or an online class before saving.
4. Check the calendar in month/week/list view and edit or cancel through the event action if details change.

Online class sessions created from eLearning may also appear as calendar events. Avoid creating a duplicate manually; edit the source session when the event is linked to one.


## Setup, updates, and verification

### Maintain the calendar

Before creating an event, decide its audience and check the calendar for an existing event/session to avoid duplicates. When editing, recheck date, timezone, audience, and any online link, then confirm it appears in the expected calendar view. If the event came from an eLearning session, update or cancel the session at its source. Use export only when your role permits it and the audience is authorized to receive the data.

**Access:** Events permissions control viewing, create, edit, delete, and export. Visibility depends on event audience and the user's school/class relationship.
