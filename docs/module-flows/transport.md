# Transport

## Configure routes and assign students

1. Open **Transport** and create the routes/vehicles or stops used by the school.
2. Review route names, capacity, stops, and any operational details before saving.
3. Assign the correct students to a route and confirm the assignment in the roster.
4. Update the assignment when a student changes transport; remove the old assignment only after confirming the replacement.
5. Review route/student lists for duplicates or missing assignments.


## Setup, updates, and verification

### Maintain routes and student assignments

Set up routes, stops, and vehicles before assigning students. Confirm pickup/drop-off details and capacity, then verify the student in the route roster. For a route change, assign the replacement using the supported flow and confirm it before ending the old assignment. Review route rosters periodically for inactive students and duplicate assignments; contact families through Messages or the approved notification process if required.

**Access:** Transport permissions separate viewing, route management, student assignment, and deletion. A change to transport data does not itself notify families unless the configured notification workflow does so.
