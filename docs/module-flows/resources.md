# Resources

## Share a resource

1. Open **Resources** and choose the add/share action.
2. Enter a clear title, description, URL or supported attachment details, and audience/class if requested.
3. Check the link and visibility before saving.
4. Use edit/delete controls to maintain resources you are authorized to manage; check whether a shared link is still valid before redistributing it.

Do not upload confidential records as general learning resources. Use the dedicated student, HR, or medical workflow for sensitive records.


## Setup, updates, and verification

### Maintain shared resources

Before creating a resource, check the audience and ensure the URL/attachment is appropriate for that audience. Use the intended class or school visibility, then open the saved resource as a permitted recipient to verify access. Update the existing item when a link changes; remove expired or superseded resources through the authorized action. Store confidential records in their dedicated module rather than a broadly shared resource.

**Access:** Resources module permissions control read, create, update, and delete; visibility is also constrained by school/audience rules.
